# White Pixl 菜单、About、Contact 与社交图标更新设计

日期：2026-07-17

## 目标

依据用户提供的 `browse-04.png`、`Desktop-05.png`、`717-03.png` 与 `资源 16-8.png` 更新现有静态官网。保留首页、项目卡片、项目悬停文字、页脚 CTA 及现有页面跳转行为，仅替换本次指定区域，并同步发布至 GitHub Pages。

## 范围

### Project 菜单

- 菜单项由 `All / Type / Media / Search` 调整为 `All / Type / Service / Search`。
- `Type` 分类调整为：
  - 3C & Tech
  - Automotive
  - FMCG
  - Beauty & Fashion
  - Short film
- `Service` 分类调整为：
  - AI-Generated
  - CG&VFX
  - Online
- 当前分类为黑色文字并带红色下划线，其余分类为灰色。
- 分类面板字号与顶部菜单保持一致，避免出现过大的细分文字。
- `Search` 保留现有筛选能力，输入栏外观按参考图调整。
- 项目卡片与筛选数据同步重映射，保证每个菜单选项能够筛出对应项目。

### About 页面

- 保留居中的 White Pixl 标志与右侧导航。
- 页面标题按参考稿显示 `CREATIVE LAB.` 与 `EXPERIMENTAL`。
- 顶部三组介绍内容采用左侧短标题、右侧正文的双栏结构。
- 第一张工作室图片保持全宽展示，并保留左下角方向箭头。
- 第二部分改为左侧竖版办公图片、右侧两段介绍文字。
- `Clients & Collaborations` 区域改为三条独立循环轨道：
  - 第一、第三行从右向左移动。
  - 第二行从左向右移动。
  - 三行速度略有差异，形成自然层次。
  - 每条轨道复制内容实现无缝循环。
  - 鼠标悬停时暂停。
  - 系统开启“减少动态效果”时停止动画并显示静态排列。
- 页脚文案、CTA 与联系方式保持现有内容和跳转逻辑。

### Contact 页面

- 页面结构与 `Desktop-05.png` 对齐：大标题、左侧联系方式、右侧地图、底部大号文案与页脚。
- 联系方式替换为：
  - Address：`3RD FLOOR, NO. 553, MAOTAI ROAD, CHANGNING DISTRICT, SHANGHAI, CHINA`
  - Tel：`021-62262933`
  - E-mail：`WHITEPIXL@VIP.COM`
  - Keep in touch：`www.whitepixl.com / WECHAT / RED / DOUYIN`
- 地图采用新参考稿中的新版地图区域，作为本地优化图片加载，避免依赖第三方地图服务。
- 保持桌面端左右分栏，移动端纵向排列，地图不变形且无横向溢出。

### 全站右下角社交图标

- 首页、Project、About、Contact 统一使用用户提供的微信、小红书、抖音灰色图标。
- 使用提供的透明图片资源保证外观完全一致。
- 图标组维持右下角对齐，桌面端按参考尺寸展示，移动端等比缩小。
- 图标图片提供可读的替代文字；在没有明确外链地址前，不添加错误的第三方跳转。

## 响应式规则

- 桌面端保持参考稿的大留白、双栏结构和底部右对齐。
- Project 菜单在窄屏允许横向滚动，不压缩成不可读文字。
- About 的三行 logo 动画在移动端降低图标高度与轨道间距。
- Contact 的信息与地图在窄屏改为单列，标题字号使用流式缩放。
- 所有页面必须保证 320px 宽度下无横向滚动条。

## 资源处理

- 从用户提供的 Contact 参考图中无损裁切地图区域，保存为独立网站资源。
- 从 About 参考图中裁切第二张竖版办公图片，仅做机械裁切，不生成新视觉内容。
- 社交图标直接复制用户提供的透明 PNG 到网站资源目录。
- 现有 logo 行图片继续复用，并重组为三条连续轨道。

## 保留项

- 首页内容与项目顺序保持不变。
- Project 卡片图片和随鼠标出现的 `OPEN / watch / see case` 交互保持不变。
- 所有页面的 `Get in touch!` 继续跳转到 `contact.html`。
- 现有 White Pixl 标志、导航跳转与页面基础字体保持不变。
